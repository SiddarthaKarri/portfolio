# AlgoGeeks

A full-stack MERN coding and contest platform designed for students at GVPCE to practice coding and compete in live challenges.

## Features

- **Online Coding & Contests**: Built a platform serving 100+ students for coding practice and competitions.
- **Interactive Dashboards**: Features include a custom judge, user dashboards, live rankings, and peer battles with a comprehensive admin panel.
- **Secure Code Execution**: Integrated a C++ code execution backend using Docker sandboxing for isolated and safe processing.

## Tech Stack

- **Frontend**: React
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Infrastructure**: Docker (Sandboxing), C++
