# LeetForces

A unified dashboard for competitive programmers to track their progress across LeetCode and Codeforces.

## Features

- **Unified Stats**: See your solved count from LeetCode and rating from Codeforces in one place.
- **Submission History**: Visualizing daily activity and problem difficulty distribution.
- **Compare**: Compare your stats with friends.

## Tech Stack

- **Frontend**: React, Vite
- **Data Visualization**: Recharts
- **APIs**: LeetCode GraphQL API, Codeforces Public API

## Development Process

Handling the CORS issues with LeetCode's GraphQL API required setting up a proxy or using a client-side solution that respects browser security policies.
